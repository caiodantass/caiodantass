## ⚡ Sobre Mim

Desenvolvedor apaixonado por construir software robusto, escalável e bem arquitetado — desde o controle de periféricos em microcontroladores até plataformas web distribuídas integradas a Inteligência Artificial.

* 🤖 **IA Generativa & RAG**: Criação de assistentes inteligentes com agentes autônomos, busca semântica vetorial e *function calling*.
* 🌐 **Full-Stack Moderno**: Desenvolvimento de APIs reativas em Node.js (Express) e Python (FastAPI), com interfaces dinâmicas em React, Vite e Tailwind CSS.
* 📡 **Sistemas Embarcados & IoT**: Programação em C com FreeRTOS e ESP-IDF sobre ESP32, integrando protocolos I2C, SPI e sensores industriais.
* 🧠 **Fundamentos Sólidos de Computação**: Aplicação prática de Teoria dos Grafos, C++ Orientado a Objetos e Processamento Digital de Sinais.
